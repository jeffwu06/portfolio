Project 05

Ping Pong Launcher

The goal for this project was to reverse engineer an existing design of a remote-controlled ping pong launcher and help make the design more efficient and easier to build.

Major skills

Programming an Arduino

Documentation & Research

Manufacturing - Soldering, 3D printing, wiring a circuit board, servos, DC motors.

Process

To first understand the original design, I built the product as is. During this process, I was careful to think of how the target audience might approach the design, and noted any issues I found.

The original design implements servos and DC motors to spin a flywheel to launch ping pong balls. Not only that, the base could be rotated using a joystick. This core design worked very well and minimal changes were made. However, I noticed that sometimes the ping pongs would not launch straight. To fix this, I repositioned the servo motors to allow for the ping pongs to launch cleaner.

The assembly also had a few obstacles such as parts not fitting correctly, screws being too tight, or the wiring of the servos. To fix this, I remodeled some of the parts, allowing them to connect easier and the screw holes.

Outcome

Through this project, I helped create a new set of assembly instructions specifically targeted for kids. Not only that, I also learnt how to use an Arduino board and servo motors.
